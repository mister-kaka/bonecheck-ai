# Тестирование

Проверки API лежат в `backend/`. Интерфейс проверяется сборкой.

Команды выполняются из каталога `backend/` после `npm install`, если не сказано иное.

## Модульные тесты API

```bash
cd backend
npm test
```

Проверяются:

- приём DICOM по имени и типу, отказ пустого и слишком большого файла;
- разбор ZIP: пустой архив, отсутствие DICOM, посторонний файл, небезопасный путь, повтор имени, лимит числа файлов и размера;
- создание исследования, статус, результат и ошибка анализа;
- история и фильтр по сессии;
- сохранение записей после перезапуска;
- файл на диске и отказ, если файла нет;
- сборка XLSX и время по Москве;
- формат ошибок HTTP;
- ответ `/health`.

## Сквозные тесты API

```bash
cd backend
npm run test:e2e
```

Поднимается приложение и проверяются HTTP-ответы:

- `GET /health`;
- загрузка DICOM: создание, статус, результат, пустой файл, неверный тип, неверный идентификатор, неизвестное исследование;
- история: фильтр сессии, пустой список, лишние query-параметры, слишком длинная сессия;
- сохранение исследования после перезапуска приложения;
- ZIP: принятие DICOM и отказ некорректных архивов;
- XLSX: одно исследование, несколько, пустая выборка, неизвестный идентификатор;
- наличие методов выгрузки и пакета в описании API.

## Сборка интерфейса

```bash
cd frontend
npm run build
```

Команда проверяет типы и собирает интерфейс. Если она завершается без ошибки, сборка прошла.

Команды выше процент покрытия не выводят.
