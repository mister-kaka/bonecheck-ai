# Ошибки и граничные случаи

Сообщения ниже видит пользователь. Коды HTTP - в [api.md](../system/api.md).

Оглавление: [README.md](../README.md).

## Файл не принят

Заголовок экрана: «Файл не принят». Исследование не создаётся.

| Ситуация | Что видит пользователь |
| --- | --- |
| Не DICOM и не ZIP | «Некорректный формат файла. Ожидается DICOM (.dcm / .dicom).» или «Ожидается ZIP-архив (.zip).» |
| Пустой файл | «Файл исследования пустой.» или «Архив пустой.» |
| Файл больше 50 МБ | «Файл слишком большой. Максимальный размер - 50 МБ.» |
| Папка или несколько файлов сразу | просьба выбрать один DICOM или один ZIP |
| Пустой архив | «Архив пустой.» |
| В архиве нет DICOM | «В архиве нет DICOM-файлов.» |
| В архиве есть посторонний файл | этот файл назван в тексте отказа |
| Повреждённый ZIP | «Архив повреждён или не является ZIP.» |
| Небезопасный путь внутри ZIP | архив не распаковывается |
| Два одинаковых имени DICOM | повтор назван в тексте отказа |
| Слишком много файлов в ZIP | максимум 30 |
| Слишком большой файл внутри или слишком большой распакованный объём | отказ с кодом превышения размера |

Кнопка «Загрузить другой файл» возвращает к выбору.

## Проверка не выполнена

Заголовок: «Проверка не выполнена».

Обычный текст: «Не удалось проверить качество укладки.»

В истории у такой записи статус «Ошибка анализа». Результат по ней не показывается. Повторный запуск API эту запись заново не проверяет.

Остальные исследования при этом не меняются.

## Сервер недоступен

Если API не запущен или не отвечает:

- «Не удалось связаться с сервером. Проверьте соединение и попробуйте ещё раз.»
- «Сервер не ответил вовремя. Попробуйте ещё раз.»

На истории в этом случае: «Не удалось загрузить историю» и кнопка «Повторить».

Сбой на стороне API без отдельного текста возвращает «Не удалось обработать запрос. Попробуйте ещё раз.»

## Исследование ещё обрабатывается

Статус «Идёт анализ». Результата ещё нет.

На экране анализа можно подождать. Если ожидание на этом экране уже долгое, предлагается продолжить его или открыть историю.

В карточке написано: «Результат анализа ещё не готов.» Статус обновляется сам. Запрос результата в этот момент не отдаёт оценку.

Если API остановили во время анализа, после следующего запуска проверка таких записей продолжается.

## Исследование завершено

Статус «Готово». Открываются область, критерии и снимок. Повторная загрузка страницы показывает тот же результат.

«Экспорт XLSX» в этот момент скачивает таблицу. Пока кнопка в работе, её подпись - «Выгрузка...».

## Исследования нет

Карточка с неизвестным адресом показывает «Исследование недоступно». Можно повторить запрос или вернуться в историю.

Если запись есть, а файла снимка на диске уже нет, карточка сообщает: «Файл исследования не найден.»

## Просмотр снимка

Проверка может быть готова, а изображение не открыться. Тогда на месте снимка текст:

- «Не удалось открыть снимок.»
- «Не удалось прочитать снимок. Файл может быть повреждён.»
- «Сжатый DICOM в просмотре не поддерживается.»
- «В просмотре поддерживаются только одноканальные снимки.»
- «Эта глубина изображения в просмотре не поддерживается.»
- «Снимок сохранён на сервере, но не удалось открыть его в просмотрщике.»

## Выгрузка

Неизвестный идентификатор в выгрузке не создаёт файл. Слишком длинный список идентификаторов отклоняется: не больше 200 за один запрос.

Пустая история без сужающих фильтров скачивает таблицу только с заголовками. Выборка, которую фильтры сузили до нуля, не выгружается: «По выбранным фильтрам нет исследований для выгрузки.»

## Ожидание прервано на экране

«Прервать ожидание» перестаёт обновлять этот экран. Уже принятое исследование остаётся в истории и доходит до «Готово» или «Ошибка анализа» без этого экрана.
