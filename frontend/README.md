# Frontend

Интерфейс BoneCheck AI. Через него загружают исследование, смотрят результат, снимок и историю.

Публичный прототип: https://bonecheck-ai.onrender.com/

## Запуск

Локальный запуск из этой папки. Нужен Node.js 20. API должен быть запущен отдельно.

```bash
npm install
npm run dev
```

Локальный интерфейс: http://localhost:5173

Полная инструкция: [запуск](../docs/system/running.md).
