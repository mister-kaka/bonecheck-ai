# Результат анализа

Результат относится к одному изображению. Он описывает качество укладки, а не состояние пациента и не минеральную плотность кости.

Оглавление: [README.md](../README.md).

## Что видно на экране

Готовый результат называется «Результат проверки укладки».

| На экране | Когда |
| --- | --- |
| Укладка корректна | нарушений нет |
| Нарушение качества укладки | найдено одно или несколько нарушений |
| Без нарушений | метка при корректной укладке |
| Нарушение | метка при найденной проблеме |
| Анатомическая область | поясничный отдел позвоночника или проксимальный отдел бедра |
| Вероятность нарушения | проценты, только если значение передано в результате |
| Обнаруженные нарушения | список формулировок |
| Критерии области | каждый критерий этой области: «Нарушение» или «Без нарушений» |

Текст под результатом:

- «Нарушений качества укладки не обнаружено.»
- «Обнаружено нарушение качества укладки.»
- «Обнаружено несколько нарушений качества укладки.»

Под вероятностью указано: это вероятность нарушения качества укладки, а не уверенность диагноза.

## Класс качества

| Значение | Смысл | Подпись в XLSX |
| --- | --- | --- |
| 0 | изображение корректно | Корректно |
| 1 | есть нарушение качества | Нарушение |

В сохранённом результате класс 0 идёт с пустым списком нарушений. Класс 1 идёт хотя бы с одним нарушением выбранной области.

Если хотя бы один критерий нарушен, изображение считается некорректным.

## Анатомические области

Допустимы только две формулировки:

- Поясничный отдел позвоночника
- Проксимальный отдел бедра

Сторона бедра, левая или правая, в область не входит. Область не берётся из имени файла. Ширина 300 столбцов - поясничный отдел, 280 - проксимальный отдел бедра. Другая ширина относится к ближайшей из этих двух, при равном расстоянии - к бедру.

Набор критериев зависит от области. На экране показываются критерии только этой области.

## Поясничный отдел позвоночника

| Нарушение | Смысл |
| --- | --- |
| Некорректная укладка | положение пациента на снимке не соответствует требованиям укладки |
| Не выравнена ось позвоночника | наклон оси относительно вертикали изображения признан нарушением |
| Присутствуют посторонние предметы | в поле снимка есть посторонние предметы |

Угол считается по яркой средней линии снимка. Решение принимает модель по этому углу. Сравнения с фиксированными 5 градусами нет: 5 градусов - клинический критерий задания. Вертикаль - ось изображения. Сколиоз сам по себе не является типом нарушения.

## Проксимальный отдел бедра

| Нарушение | Смысл |
| --- | --- |
| Некорректная укладка | положение и ротация бедра объединены в один тип |
| Некорректная область интереса | исследуемая зона показана не полностью |

«Некорректная область интереса» - это полнота визуализации зоны, а не разметка ROI денситометра. В проверке это короткая высота кадра, а не измерение полей 3 см и 2 см. Белые полосы аппаратной разметки есть не на всех снимках и не являются отдельным типом нарушения. Подробнее: [limitations.md](limitations.md).

## Несколько нарушений

Несколько типов записываются одной строкой и разделяются точкой с запятой, без пробела после разделителя:

```text
Не выравнена ось позвоночника;Некорректная укладка
```

Если нарушений нет, строка типов пустая. В истории пустой тип у готового исследования показывается как «Без нарушений». Пока результата нет, в колонке «Нарушение» стоит «-».

Повтор одного и того же типа и нарушение из другой области в результат не принимаются: такая проверка завершается ошибкой анализа.

## Вероятность

Поле необязательное. Если оно есть, это число от 0 до 1. На экране оно показывается в процентах, с округлением до целого. Текущая модель его не передаёт, в журнале колонки вероятности нет.

Основной итог - класс качества. Вероятность его не заменяет.

## Граница результата

Результат не содержит диагноза, T-score, минеральной плотности и описания сопутствующих находок. Сколиоз, перелом, эндопротез и люмболизация не входят в список нарушений укладки.

Чёрные прямоугольные области на снимке - маскирование мягких тканей после обработки денситометра. Это не тип нарушения.

## Файл сдачи

Журнал с экрана истории - другой файл. В нём русские колонки и слова «Корректно» / «Нарушение».

Файл для проверки по ТЗ: `GET /api/studies/submission`.

Колонки: `path_to_study`, `study_uid`, `image_uid`, `anatomical_region`, `quality_class`, `violation_type`, `processing_status`, `time_of_processing`.

`quality_class` в этом файле - число. `study_uid` и `image_uid` берутся из тегов DICOM. В ответе API колонка `path_to_study` содержит исходное имя файла, не путь на диске.
