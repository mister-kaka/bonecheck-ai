# Продукт

## Название

BoneCheck AI.

## Назначение

BoneCheck AI оценивает качество DXA-исследования: корректность укладки и полноту визуализации исследуемой области.

Результат нужен до того, как снимок использует врач. Это проверка качества получения изображения, а не медицинское заключение.

В шапке интерфейса указано: «Проверка качества укладки. Не диагноз и не измерение минеральной плотности.»

## Для кого

- врач-рентгенолог;
- сотрудник отделения лучевой диагностики;
- эксперт, который проверяет, как система принимает исследование и показывает результат.

Вход в систему не требуется. Раздел «Мои» в истории показывает загрузки этого браузера. Раздел «Все» показывает общую историю, которую хранит этот экземпляр системы.

## Какую задачу решает

У денситометрии качество снимка зависит от укладки. Неверное положение, сдвиг области интереса, посторонние предметы или невыровненная ось позвоночника делают исследование непригодным для дальнейшей работы.

BoneCheck AI принимает DICOM, проверяет укладку и показывает, что именно нарушено.

## Что анализируется

Две анатомические области:

| Область | Что может быть отмечено |
| --- | --- |
| Поясничный отдел позвоночника | некорректная укладка, невыровненная ось позвоночника, посторонние предметы |
| Проксимальный отдел бедра | некорректная укладка, некорректная область интереса |

Сторона бедра в результате не указывается.

Исследования задачи получены на аппарате Lunar Prodigy Advance. Система принимает DICOM-файлы этих областей.

## Основной сценарий

Пользователь открывает «Анализ», загружает один DICOM или ZIP, дожидается проверки и видит результат по каждому снимку. Готовое исследование остаётся в истории. Результат можно открыть снова и выгрузить в XLSX.

Пошагово: [scenario.md](scenario.md).

## Ценность

- проверка укладки вынесена в отдельный понятный результат;
- нарушения названы формулировками задачи, без клинического диагноза;
- снимок можно посмотреть рядом с результатом;
- несколько исследований из одного архива не смешиваются в одну оценку;
- история и XLSX позволяют вернуться к уже проверенным файлам.

## Возможности

| Возможность | Что даёт пользователю |
| --- | --- |
| Загрузка DICOM | Один снимок уходит на проверку с экрана «Анализ» |
| Загрузка ZIP | Несколько снимков принимаются одним архивом, каждый становится отдельным исследованием |
| Проверка файла | Неподходящий формат, пустой или слишком большой файл отклоняется до анализа |
| Статус обработки | Видно, что файл загружается или проверка ещё идёт |
| Результат | «Укладка корректна» или «Нарушение качества укладки», область и критерии |
| Нарушения | Список найденных типов и отметка по каждому критерию области |
| Две анатомические области | Поясничный отдел позвоночника и проксимальный отдел бедра |
| Просмотр снимка | Изображение рядом с результатом, масштаб и сдвиг |
| История | Журнал своих и всех загрузок |
| Фильтры и страницы | Поиск по имени файла, область, результат, тип нарушения, даты, сортировка, размер страницы |
| Карточка исследования | Статус, результат и снимок по записи из истории |
| Экспорт XLSX | Таблица по одному исследованию или по текущей выборке истории |
| Ошибки | Отдельные сообщения, если файл не принят или проверка не выполнена |
| Адаптивный интерфейс | Экраны анализа, результата и истории перестраиваются на узкой ширине |

Смысл полей результата: [results.md](results.md).
